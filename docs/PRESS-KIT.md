## 4. Pitching & Event Execution Rules

1. **Personalise**: Customise the first line with a reference to a real piece written by the recipient.
2. **Concise**: Under 150 words, one core idea, single clear call to action.
3. **Domain Sender**: Always send from `contact@glowvai.in`, never from personal free webmail.
4. **No Large Attachments**: Never attach files over 1MB. Link to `https://glowvai.in/press`.
5. **Follow-Up Limit**: Follow up at most ONCE, 5 to 7 days after initial pitch.
6. **Disclosure**: Always disclose gifted products or free access as required by ASCI guidelines.

## 5. Event Kit Checklist

- **QR Code Poster**: Links to `https://glowvai.in/face-analysis?utm_source=event&utm_campaign=EVENTNAME`
- **Consent Sign**: *"Free scan. Your photo is analysed on your phone. Saving it is optional."*
- **Printed Media Sheets**: 10 copies for press/organisers.
- **Photo Consent**: Photograph faces only with explicit verbal and written consent.
- **Post-Event**: Publish thank-you post, tag organisers, add media mentions to `/press` page.
